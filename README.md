# Google Antigravity - Sports Prediction Bot

## Setup

1. **Install Dependencies**
   ```bash
   pip3 install -r requirements.txt
   ```

2. **Configuration**
   Set the `TELEGRAM_TOKEN` environment variable.
   ```bash
   export TELEGRAM_TOKEN="your_token_here"
   ```

3. **Run**
   ```bash
   python3 main.py
   ```
